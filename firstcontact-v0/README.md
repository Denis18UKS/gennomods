# Project: First Contact 0.4.0 — радиоэкспедиции

NeoForge 1.21.1 / Java 21 / Create / JEI / Create: Radars / Create: Aeronautics

## Радиопередачи с координатами
- В радиосети восемь новых скрытых частот со сведениями о загадочных местах, закодированными азбукой Морзе.
- Система использует seed мира. Радио передаёт X и Z без игрового переводчика. Оригинальный Морзе можно скопировать в буфер кнопкой КОПИЯ.
- Не каждая частота активна: вероятность передатчиков меняется каждые 60 игровых секунд. Радио проверяет эфир даже пока GUI открыт.
- Все старые 17 станций и сюжетная передача 98.7 MHz сохранены.

## Новые заброшенные структуры Create
- На X/Z около 4400–10900 блоков от (0,0) рассчитано восемь потенциальных мест экспедиции.
- Исход зависит от seed: пустые координаты, полуразрушенные или целые заброшенные мастерские с механизмами Create. Часть руин содержит небольшой тайник с предметами Create.
- Структуры генерируются ИСКЛЮЧИТЕЛЬНО при первой генерации НОВОГО чанка в обычном мире, никогда не вставляются при загрузке, приближении игрока, чтении радио или входе на сервер.
- Площадка 7×7 блоков целиком внутри одного чанка. Перед стройкой проверяется 49 блоков поверхности, природный грунт, ровность рельефа и отсутствие препятствий, чужих строений или воды.
- На существующие чанки и постройки игроков мод НЕ воздействует. Если координаты уже исследованы до установки мода, место может быть пустым. При неудобном рельефе генерация отменяется.

## JEI-мультиблок Radar Bearing
- Категория JEI: Реальный радар Create: Radars (3D), схема диаметром 13, высотой 6 блоков.
- Настоящие детали: Radar Bearing, Radar Receiver, Radar Dish, Radar Plate, опора из Create Brass Casing.
- Поддерживает поворот мышью, масштаб колесом и просмотр послойно.
- JEI и команда /firstcontact radar check используют ЕДИНЫЙ blueprint-каталог с точными координатами всех блоков.
- /firstcontact radar blueprint печатает количество материалов. /firstcontact radar check показывает сколько блоков отсутствует и первое нужное смещение XYZ от Radar Bearing.
- Склейте движущиеся блоки Super Glue, подключите кинетику и выполните /firstcontact radar link.
- Это 3D-инструкция, а НЕ NBT для Create Schematicannon.

## Крафт радио (3×3)
Brass Casing | Electron Tube | Brass Casing
Copper Sheet | Precision Mechanism | Copper Sheet
Brass Casing | Note Block | Brass Casing
Итого: 4 Brass Casing, 1 Electron Tube, 2 Copper Sheet, 1 Precision Mechanism, 1 Note Block. Рецепт виден в JEI.

## Исключение радио из Masterki Economy
- First Contact при старте сервера добавляет только firstcontact:radio_receiver в config/masterki/blocked_items.json; все остальные пункты файла сохраняются.
- Перезагружает политику и очищает кэш каталога Masterki Economy 1.0.14, так что радио нельзя купить за мастерки.
- Мод Masterki Economy 1.0.14 НЕ пересобирается и не изменяется. Если JSON повреждён, запись не перезаписывается: ошибка попадает в лог, требуется ручное исправление конфигурации.

## Тестирование
1. Удали старый First Contact, поставь 0.4.0 на сервер и клиент; перед новой генерацией мира рекомендуется бэкап.
2. Получить радио: /give @s firstcontact:radio_receiver. Для сюжета: /firstcontact ready, ожидание 60 игровых секунд, частота 98.7.
3. Искать передачи кнопкой ПОИСК или крутить частоту вручную 50.0–180.0 с шагом 0.1 MHz.
4. Ловить кодовые сигналы, копировать необработанный Морзе и расшифровывать самостоятельно. Никакой кнопки расшифровки нет.
5. Изучать X/Z-координаты: в некоторых новых чанках появятся структуры Create, в других ничего не будет.
6. Схему радара открыть из JEI через рецепты радиоприёмника или Radar Bearing.

## Сборка и ограничения
- Java 21, Gradle 9.2.1, Python 3, ffmpeg; gradle -p firstcontact-v0 clean build. GitHub Actions собирает JAR и архив исходников.
- Все радиосигналы вымышленные, а не реальные передачи.
- Не гарантирована генерация строений в ранее созданных чанках. Существующие базы и чанки остаются без изменений.
- Корабль Aeronautics/Sable пока проверяется как физическая сборка, но не на наличие двигателей.
- Полная проверка в пользовательской сборке с шейдерами требует запуска Minecraft.

Masterki Economy 1.0.14 и Player Utilities остаются нетронутыми.
